# October 8: local live walking fidelity

The 32-longitude developer garment still uses 24 surface rows. The shared live
walker now adds 48 virtual longitudinal intervals when querying selected curved
solids. These points are not rendered, skinned donors or persistent simulation
particles. The measured Wolverine adapter selects its two testicle ovoids;
every other collider still participates in the existing provisional walk and
the final whole-triangle separation certificate.

The virtual samples use the current pose and each ordered longitude half-plane.
Their outward convex envelope joins the original surface samples, fixed sewn
boundary and terminal pole. Surface rows are redistributed by arc length plus
local turning angle, placing more of the existing vertex budget around bends.
Positive arc-length density retains samples along straight spans. Ray origins,
seam aliases, UV lineage, bind donors and the revision-5 topology are unchanged.
This improves live longitudinal sampling; it does not implement live origin
redistribution, exact geodesics or full cloth self-contact.

`ClearMeridians` takes an optional final `detailedHullFirst` index (default zero:
refine all supplied hulls). A port may identify the start of its curved-collider
suffix from its own measured rig. The index is validated; shared code has no
game, character or skeleton assumptions. Existing callers remain compatible.
Work is bounded at 48 virtual intervals per longitude and the existing 12
certificate iterations. Failed poses remain transactional and use the adapter's
existing continuity path. These changes never reduce anatomy or cloth cadence.

The SDK-free clearance test adds a narrow oblate support between render rows.
It checks that the contact bulge survives without increasing the mesh, changing
the anchors or leaving a longitude plane. The current walker passes; compiling
that same test against the previous installed build's shared header fails with
`Sub-row curved support vanished from the taut path`. Existing moving-obstacle,
full-face, cache, seam and transactional-rejection tests also pass.

The exact 32-column private native pose bank contains 16 poses. Six-repeat CPU
replay reports total means of 5.63073 ms before and 5.78195 ms after, with identical
fallback counts and no outer failures. The all-collider refinement experiment
cost 6.49633 ms and was not selected. These are post-skinning CPU samples, not
FPS measurements or proof of every motion/shape configuration. Private receipts
are under build/fidelity-20261008 and are excluded from Git and release assets.
