# Radial recruitment and clinical adoption

The source numerical worker now accepts target rest-position collar queries.
It evaluates the original UnifiedCollar radial target expression with the
cached recruitment metric and the current final Raphe guide. This avoids
blurring a sparse target pelvis through the nearest eight source vertices.
Adapters retain their own skin palettes and body resource boundaries. Both
sides of a body weld must consume the same canonical boundary field.

Wire version 4 carries these query displacements, the final distal nozzle,
and the clinical projection. The clinical clock is binary64; source pulse
envelopes, mapping, lateral variation and angle variation retain their source
expressions. Source process arithmetic remains the measured Win32 recipe.
The immutable imported Wolverine files have not been edited.

`clinical::AmbientClock` owns the source passive clocks. The clinical Session
owns emission, the fluid mesh, baked deposits and deferred collision paths.
`BuildDepositMesh` exposes only validated scene anchors. Game adapters own
world queries, materials, GPU lifetime, input and future dialogue assets.
Audio cue phases remain source-timed callbacks without replacement dialogue.

`malemod_base.skin_match` calculates a deterministic linear-RGB gain from
corresponding seam UV samples. `malemod_base.refinement` supplies conforming
midpoint subdivision with sparse lineage and distinct UV aliases. Exporters
must retain original seam donors and preserve locked resource boundaries.

The Witcher adapter adopts these through a new Base pin and a new native
resource/binding cook. Wolverine and the other spokes can adopt the same
versioned interfaces after their own byte replay and gameplay checks. Until
then Wolverine's installed canonical runtime remains authoritative and is
unchanged. This shared change does not certify any game port. Source parity,
offline tests, native conversion and observed gameplay are recorded separately.
