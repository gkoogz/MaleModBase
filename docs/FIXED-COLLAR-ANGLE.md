## Current shared model

measured attachment boundary. The half-space behind that boundary and a measured
box enclosing protected lower tissue remain exact equilibria. The outer shaft
follows a rigid rotation once clear of both transition regions. The field is
integrated with RK4; fully clear rotation arcs use the exact rigid transform.
This avoids multiplying displaced vertices by an inherited corrective mask.

in independent donor coordinates. The body, original-edge donors, protected
lower core, and proximal half-space are excluded from this correction. If a live transient fails projection, the shared admissibility search reduces
angular amplitude only. Both LODs are recomputed at a common feasible amplitude,
and delivered guides use the same field. The applied gain is recorded in native
telemetry. The first rejected transient source is captured privately for replay.
